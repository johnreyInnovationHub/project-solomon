🛠 Google Sheets Setup — Full Guide

Follow every step carefully. Step 4 is the most important one most people miss.

STEP 1 — Create a Google Sheet

Go to sheets.google.com and create a new spreadsheet named Project Solomon Data. No need to create any tabs — the script creates them automatically.

STEP 2 — Open Apps Script

In your Google Sheet, click Extensions → Apps Script. A code editor opens in a new tab.

STEP 3 — Paste the Code

Delete everything in the editor. Paste the full contents of Code.gs. Click the 💾 Save button (or Ctrl+S).

STEP 4 — Deploy as Web App

Click Deploy → New Deployment. Set these exact options:

Type: Web app
Execute as: Me
Who has access: Anyone

Click Deploy. Google will ask you to authorize — click through all permission prompts. After deploying, copy the Web App URL — it looks like:
https://script.google.com/macros/s/AKfycb.../exec

⭐ STEP 5 — Hardcode the URL into app.js (CRITICAL)

This is the step that makes it work on every device automatically — phones, other browsers, student devices — without anyone needing to configure anything.

1. Download js/app.js from your project files.
2. Open it in any text editor (Notepad, VS Code, etc.).
3. Find this line near the top:

const HARDCODED_API_URL = 'YOUR_APPS_SCRIPT_URL_HERE';

4. Replace YOUR_APPS_SCRIPT_URL_HERE with your actual URL:

const HARDCODED_API_URL = 'https://script.google.com/macros/s/AKfycb.../exec';

5. Save the file. Upload it to Netlify (drag the updated ZIP onto the Deploys tab).

STEP 6 — Test it

1. Open projectsolomon.netlify.app/student on your phone.
2. Register a test student.
3. Open the teacher dashboard on your computer — the student should appear in Enrollment within seconds.
